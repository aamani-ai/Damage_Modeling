# winter storm notebooks

Notebook companions for winter-storm damage-curve cells.

## Cells

| Asset | Notebook folder | Current purpose |
|---|---|---|
| Solar PV | [`solar/`](solar/) | Curation walkthrough for the proposed `winter_storm_solar` model v0.1 screening curves. |

`winter_storm_wind` has no notebook: its model v0.1 is a fail-closed scaffold with no curve to walk through.

## Boundary

These notebooks explain the damage layer for winter storms: snow (and glaze) load to damage ratio, plus an
optional conditional loss when an explicit value basis is supplied. Event frequency, EAL, PML, VaR and TVaR
remain in the Hazard modeling tier.
