# docs/source_drops/

Index for raw or source-context material that supports the damage-modeling docs.

This folder is an index-only surface for now. Source material is preserved in place until a reviewed migration
decides what should move, what should stay bundled with a deliverable, and what should remain as external
reference context.

## Rule

Raw source drops are evidence inputs and provenance support. They should be preserved and indexed, not used as
the primary navigation layer for current cells or contracts.
