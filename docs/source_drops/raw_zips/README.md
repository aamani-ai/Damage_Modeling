# docs/source_drops/raw_zips/

Home for untouched raw ZIP files and original uploaded bundles.

Use this folder only for source material. These files are provenance inputs, not current docs and not runtime
artifacts. ZIP files are ignored by default at the repo level; force-add only reviewed, small source drops
with a manifest. If a ZIP is too large or unsuitable for git, leave it outside git and add a manifest entry
under `../manifests/` with its external location and checksum.
