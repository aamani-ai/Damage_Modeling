# docs/source_drops/manifests/

Home for source-drop inventories, checksums, provenance notes, and ingestion status.

Each manifest should record the source-drop name, received date, owner/source, storage path, checksum when
available, extraction status, related cell(s), and whether the material has been harvested into a current
curve package.
