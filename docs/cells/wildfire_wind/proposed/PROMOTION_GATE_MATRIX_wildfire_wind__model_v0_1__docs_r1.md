## Honest promotion paths

### Screening-grade v1

A coverage-first screening model is permissible only after an explicit Tier-4 business decision. It must
use a documented elicitation protocol, exact applicability bounds, visible assumption IDs, uncertainty,
conservative missing-state rules, value/dependency checks, and independent review. It must not inherit the
solar table or legacy logistics.

### Calibration-grade v1

The stronger path uses external-wildfire product/field data, local target attack, inspected equipment
states, owner/OEM work orders or claims, same-unit costs, and exact site exposure/value. Response can be
parameterized only within the supported population and validity domain.

### Separate future capability

Suppression-agent/water damage, ordinary cleaning, chronic contamination/fouling, downtime, derating, and
business interruption require separately governed pathways or downstream stages. They are not silently
added to this physical-destruction curve.

No option activates automatically. Model v0.1 remains the honest package until a reviewed model-v1.0
release is explicitly published.
