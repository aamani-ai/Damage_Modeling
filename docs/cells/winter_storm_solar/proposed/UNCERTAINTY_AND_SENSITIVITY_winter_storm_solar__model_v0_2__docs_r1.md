Assumptions with no numeric sensitivity, and why:

- **Under-designed share** — the branch has no sourced capacity (its 0.56 mapping is unsourced) and no share; any mixture would sit between the compliant result and the parked branch. It is not run, so 0.56 enters no result.
- **Tilt shedding** — no parameter or source; not modelled.
- **Risk Category I default** — no effect inside the curve; it selects which pg map Hazard supplies. Assuming I for a plant built to II overstates damage (the tolerable screening error).
- **Clearance-versus-depth flag, northern-design flag** — flags only.
- **Exposed fraction by size class** — none governed; the NITE shares (73/45/4%) are a calibration target for exposed fraction × conditional failure, and the medium/large classes rest on 23 accidents together.

## 7. Conversion chain and uncertainty type

| Step | What happens | Uncertainty type |
|---|---|---|
| SWE → ground load | × 0.00980665 kPa/mm | measured physics (none beyond the hazard input) |
| Ground → array load | × Cs 1.0 × 0.7 × Ce 0.9 × Ct 1.2 | code rule (ASCE 7-22 via secondary) + our assumption (Cs, site factors) |
| Event ÷ design | ground / pg (Risk Category I map by default) | modelled by someone else (ASCE maps) + our assumption (category) |
| Ratio → rack collapse onset | lognormal, median 1.32 / 1.88, β 0.47 | measured ratios (wind tests + one snow test) used as our assumption |
| Onset → extensive collapse | × 1.2 | our assumption |
| State → cost | 0.40 / 1.00 | measured field cases (n = 3), read by us |
| Array load → module breakage | tracker TtF 1.8–2.8 kPa × 0.85; fixed-tilt MQT 16 2.4 / 5.4 kPa × 0.85; β 0.25 | measured lab data (tracker) / standard pass level (fixed) + our assumption (knock-down, β, pass-as-median) |
| Rack collapse → module loss | 0.8 s + (1 − s) d | our assumption |
| DR → dollars | × unit value × exposed fraction (1.0 default) + support once | modelled by someone else (NREL/NLR costs) + our assumption (exposure, allocation) |
| Glaze (separate) | π t_d × 900 × g × 0.6/0.8 on the array | code rule (ASCE 7-10) + our assumption (radial = t_d, plate on array) |
