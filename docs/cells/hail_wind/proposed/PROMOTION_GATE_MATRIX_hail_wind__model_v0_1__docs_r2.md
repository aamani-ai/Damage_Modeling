## Evidence packages that can close the blockers

### Package A - owner/OEM occurrence cohort

- event-resolved hail product plus local sensor/reconstruction uncertainty;
- SCADA rotor, pitch, azimuth, operating, shutdown, and attained state;
- blade/LEP/laminate identity and pre-event condition;
- affected and unaffected visual/NDT inspections;
- final mutually exclusive disposition;
- same-blade direct work order, replacement value, and separate support cost.

### Package B - product-qualified controlled tests

- final protocol and exact test edition;
- representative full construction, ageing, repair, and prior-damage states;
- size distribution, impact speed, angle, count/history, and controls;
- functional/NDT/disposition endpoints rather than stress alone;
- replication, uncertainty, censoring, and field-transfer limits.

### Package C - claims/work-order linkage

- hail-specific peril code and event identity;
- component quantities and affected/unaffected denominator;
- exact repair/replacement scope and same-unit direct cost;
- crane/access/transport separated from intrinsic repair;
- deductible, BI, revenue, and financial terms excluded from physical DR.

### Package D - structured elicitation, only by explicit owner choice

This can create a noncanonical T4 screening proposal but does not improve the evidence-earned gate. It needs
named experts, a fixed evidence packet, calibration questions, independent uncertainty, aggregation,
conflict handling, and update triggers.

No calendar date, softer curve, borrowed solar curve, coupon threshold, or legacy cap substitutes for these
gates.
