## Outcome

This package closes the hail × wind structural-coverage gap with a pressure-tested, fail-closed contract.
It identifies the blade assembly as the primary candidate, separates operating state from asset identity,
reconciles the wind reference value ledger, governs sparse turbine/BOP exposure, and records all public and
legacy evidence dispositions.

It does not publish an occurrence economic damage curve. The recent coating-lifetime model and hail-impact
lab/simulation sources are retained as research candidates only. The alleged legacy wind-hail curve is
rejected because it is a mislabeled real-estate curve with inconsistent units and an invented plateau
extension.
