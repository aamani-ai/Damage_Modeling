# 00_governance

This folder decides **what kind of change is being made** before any files are edited.

Read order:

```text
1. CHANGE_CLASSIFIER.md
2. VERSIONING_POLICY.md
3. RELEASE_DECISION_TREE.md
4. GOVERNANCE_RULES.md
5. CELL_LIFECYCLE.md
6. DECISION_LOG_STANDARD.md
7. DEPRECATION_POLICY.md
8. REVIEW_GATES.md
```

The governance layer is intentionally stricter than normal documentation practice because downstream notebooks may consume curve artifacts as runtime contracts.
