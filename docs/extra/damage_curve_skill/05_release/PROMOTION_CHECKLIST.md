# Promotion checklist

Use this when promoting a scaffold/draft/proposed artifact to current canonical status.

```text
[ ] Change class is correct.
[ ] Cell lifecycle state is appropriate.
[ ] Reviewer gates passed.
[ ] Prior current artifact archived if replaced.
[ ] New current artifact is canonical_runtime_artifact=true.
[ ] Registry/index points to new artifact.
[ ] Deprecated/non-canonical artifacts marked.
[ ] Capability declaration supports only honest outputs.
[ ] Validation report is updated.
[ ] Release notes explain why promotion happened.
```
