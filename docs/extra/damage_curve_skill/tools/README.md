# tools

Small helper scripts for the skill package.

```text
classify_change.py          Classifies a JSON change request/signals block, including multi-pathway gates.
run_self_tests.py           Runs governance test cases.
validate_skill_bundle.py    Checks structure, JSON/Python, rigorous/pathway template headers, and fail-closed/pathway guide markers.
```

These are helpers, not a replacement for review.
