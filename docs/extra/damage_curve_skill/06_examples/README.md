# 06_examples

Governance examples that show how the skill should reason.

```text
EXAMPLE_DOCS_EVIDENCE_UPDATE_HAIL_SOLAR.md
EXAMPLE_NEW_CELL_SCAFFOLD_TORNADO_SOLAR.md
EXAMPLE_MODEL_CHANGE_STRONG_WIND_SOLAR.md
EXAMPLE_SCHEMA_CHANGE_DAMAGE_EMIT.md
EXAMPLE_FAIL_CLOSED_WILDFIRE_SOLAR_SCAFFOLD.md
EXAMPLE_MULTI_PATHWAY_REVAMP_WIND_TORNADO_WIND.md
```

The wildfire example is a controlled no-curve success case: it shows how deep research, numerical rejection, site-condition governance, value reconciliation, and fail-closed capability can be the correct outcome for a new cell.

The wind/tornado example is a controlled multi-pathway rebuild case: it keeps the current runtime pinned while a proposed major model change and required pathway schema migration are researched, tested per pathway, and validated by the Hazard consumer. It explicitly keeps tropical-cyclone/hurricane wind in a neighboring workstream.
