# Hazard pathway splitting

Do not combine physically different hazards just because the headline peril name sounds similar.

## Split when mechanisms differ

Examples:

```text
straight-line wind × solar vs tornado debris × solar
hurricane wind vs storm surge vs pluvial flood
wildfire burnover physical damage vs smoke/ash production loss
riverine flood vs pluvial flood vs coastal flood when source/coupling differs
```

## Keep together when failure units and axis remain coherent

It can be acceptable to keep related sources together when:

```text
same failure units dominate;
same hazard axis is meaningful;
same curve form is defensible;
conditioning/exposure can capture differences;
dossier explains limits.
```
