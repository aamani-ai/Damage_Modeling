# 01_workflows

Pick one workflow after running the change classifier.

| Workflow | Use when |
|---|---|
| `ADD_NEW_CELL_WORKFLOW.md` | New hazard × asset pair or scaffold |
| `UPDATE_EXISTING_CELL_WORKFLOW.md` | Existing cell changes, especially behavior-changing updates |
| `DOCS_EVIDENCE_ONLY_WORKFLOW.md` | Better docs/rationale/evidence without runtime behavior change |
| `EVIDENCE_INGESTION_WORKFLOW.md` | New references must be triaged into source roles and parameter impacts |
| `SCHEMA_CONTRACT_CHANGE_WORKFLOW.md` | JSON/emit/capability/registry contract changes |
| `RELEASE_PACKAGE_WORKFLOW.md` | Assemble a new package zip |
