*Agent decisions about how the brief was carried out. The owner's rulings are the brief itself (gate RO2).*

| # | Decision | Why |
|---|---|---|
| D1 | `validate_all.py` discovers validators by glob (`validate_*.py`, itself excluded) and runs each as a subprocess with `sys.executable` from the repository root | That is the documented invocation; the validators have module-level side effects, `sys.path` edits, `unittest` mains and `argparse` defaults that an import-based runner would disturb. Nothing in any validator changes |
| D2 | Skips are a declared, data-driven list (`PRECONDITIONS`): validator name → (check, reason). A listed validator runs normally when its check passes; an unlisted failure is `FAIL` | "Never silently": the reason is printed on the line and again in the summary. In the owner's main checkout, where the sibling `Hazard_modeling` and `outputs/` exist, all 34 run — the skip is a property of the machine, not of CI |
| D3 | Six validators are listed: the five substation bindings (`validate_substation_{convective_wind,flood,hurricane,screening,wildfire}_binding.py`) read `ROOT.parent / "Hazard_modeling"` (the flood one through `review_substation_flood_binding.py`); `validate_flood_wind_v0_1_scaffold.py` requires `outputs/flood_wind_v0_1/…xlsx`, a gitignored render copy, to compare with the governed workbook | Verified by running them in the worktree: five `FileNotFoundError` on `…/.claude/worktrees/Hazard_modeling/…`, one `FAIL output workbook missing`. Both inputs are external to a clean clone by design (`AGENTS.md`: symlinks are local-only; `outputs/` is a regenerable render target) |
| D4 | After the summary the runner prints the full stdout and stderr of every failed validator | A CI log has to show *why* a validator failed without a second run |
| D5 | `check_links.py` checks exactly the brief's scope — relative links (inline, image, reference definitions) exist; same-file `#anchors` match a heading or an explicit HTML anchor — and nothing more (no cross-file anchors, no external URLs) | Keep the gate narrow and deterministic; widen deliberately later if wanted |
| D6 | Existence is checked case-sensitively even on macOS | So a local run predicts the Linux runner; `[v](sub/FILE.md)` passes on APFS and fails on CI otherwise |
| D7 | Links into the five cross-project repositories are skipped whether they go through the gitignored root symlink (`../../Hazard_modeling/…`) **or** climb above the repository to a sibling checkout (`../../../../Hazard_modeling/…` from `docs/cells/<cell>/`) | The brief said to skip the symlinked repositories; 26 of the 100 such links use the sibling form, the same `ROOT.parent / "Hazard_modeling"` convention the substation validators use.
