# `<Hazard> × <Asset>` -- How the Model Is Built

**Purpose:** explain the governed reasoning chain after end-to-end curation without requiring the reader to
navigate the full dossier, workbook, contracts, and standards.

Start with navigation to `README.md` and `MODEL_REFERENCE.md`, then record the semantic model, human docs,
runtime pin, SHA, change class, and explicit non-change status.

```text

```
